C

部屋を、特集の扉として開く。

EDITORIAL 寄り

雑誌の特集扉の作り。部屋には一・二・三…と漢数字のノンブルが付き、大きな明朝の部屋名と極小のキャプションの対比だけで階層を作ります。 写真は図版番号付きで、段をわざと揃えずに配置。持ち物16点は左右2段の目録になります。 読ませる情報が増えるほど強くなる案。

3案に共通していること

  • キャッチコピー・タグラインは一行も置いていません。部屋の名前と事実だけで構成しています
  • 枠線・カード・区切り線を一切使っていません。階層は余白・文字サイズ・ウェイト・字間だけで作っています
  • 見出しのウェイトは200〜300のみ。極太は使っていません
  • 持ち物16点には「変わったこと ── ○○」の一行を全点に入れています
  • 数値は assets/stats.json（YouTube Data API 実測・2026-08-05）を読み込んで表示しています。サブチャンネルの数値は同日の実測を直書きしています
  • 写真は assets/photos の既存13点から選んでいます。動画テロップの文字が残っている2点（sq-01_main / p-alt-portrait）は3案とも不使用。YouTubeサムネイルも使っていません
  • 動きは IntersectionObserver と CSS transition だけ。外部ライブラリ・CDNは使っていません
